# Naiwa Motion Lab 发布候选版（rc-2026-10-18）

这是一个在浏览器里展示“动作迁移 + 软体模拟”的页面：人的动作（摄像头、上传的视频、预设舞蹈）迁移到奶蛙身上，奶蛙是骨骼外面裹着一层软肉的物理模拟。

## 打开页面先看到的

- **奶蛙**：站在荷叶上。可以戳它、拖它、拍它、扔它，往它身上扔探测球。
- **动作**：可以切换自由、摄像头、上传视频和预设动作。
  - 预设动作有 14 支：5 支是从真实视频里采的（狗熊哆嗦毛、Nae Nae、科目三、肚皮舞、企鹅踢腿），9 支是程序生成的。
  - 上传视频时，页面会先把整段分析完再同步播放。如果视频里镜头在动或有切镜，会自动修正。分析结果可以存成“我的舞蹈”。
- **手感**：不需要专业知识也能调。
  - 材质一键切换：果冻、麻薯、气球、布丁、橡皮。
  - 三个滑块：软↔硬、晃得久↔很快停、肚子小↔肚子大。
  - 两个开关：慢动作、月球重力。
  - 还有一个“恢复默认”。
- **录制**：可以只录奶蛙，也可以加画中画，或者录“真人 vs 奶蛙”并排，带视频原声。
- **其他**：支持中文和英文、亮色和暗色，手机上也能用。

## 实验室（默认收起）

- **模拟器 9 个**：
  - CPU 约束求解（默认）；
  - GPU MPM：有 GPU 时用 WebGPU，没有时自动改用 CPU 并行，页面会显示当前用的是哪一种；
  - 算法库 7 个：质点弹簧、PBD、XPBD、形状匹配、Projective Dynamics、隐式 FEM、FEM 加拉索。
- **动作迁移 8 种**：默认是“方向拷贝 + 身体约束 + 脚踩地”，另有 Kalman 和 Savitzky–Golay 两种滤波，以及 CCD、FABRIK、阻尼最小二乘、带约束优化四种求解。
- **参数和读数**：每个模拟器和动作迁移都可以调参数，并显示质量读数，比如方向偏差、四肢入体、脚滑。
- **代码实验室**：可以按模块查看源码，复制一份自己改，按 Ctrl+S 后在正在运行的模拟里生效，出错会自动回退；能和内置模块对比，旁边配有学习页。
- **学习文档**：每个算法一页中英文学习文档，附实测对比表。

## 本机 Lab（只在你自己的电脑上）

运行 `npm run lab`。如果检测到本机的 Codex CLI 已经登录，页面上会出现“与 Codex 对话”，以及这些位置的“用 Codex 优化”：

- 手感；
- 动作迁移；
- 代码模块；
- 这段动作（让视频转出来的动作更连贯）；
- 生成新舞蹈。

每次使用都会消耗你自己 ChatGPT 账号的额度。公开网站上不会出现这些入口。

## 已知问题

1. 跳舞时，默认模拟器的腿和手臂偶尔会插进身体 1–4 cm。
2. 物理计算每步约 5 ms（预算是 4 ms）。普通电脑上仍有 60 fps，较弱的电脑上可能掉帧。
3. 跳狗熊哆嗦毛时，脚抬起的那一下脚尖会在地上擦动。
4. 默认果冻戳一下晃动不够久；想看晃得久的效果，可以把手感调到最软，或者换成隐式 FEM 或 Projective Dynamics。
5. GPU MPM 在没有 GPU 的电脑上比较慢，每步 7–18 ms。
6. 跳舞时头部偶尔有一小块被拉得变形（3–8 cm）。
7. 代码实验室里保存的实验，刷新页面后要重新选一次。

## 隐私

- 所有计算都在浏览器里完成，摄像头画面和上传的视频不会离开你的电脑。
- 运行时不访问 Google：MediaPipe 的文件是自己托管的，它自带的使用统计上报已经拦掉。

## 公开发布前需要决定：版权

奶蛙是从奶龙二创来的，奶龙是第七印象的商业 IP。开源协议只能管你自己拥有的部分，管不到奶蛙的形象：

| 内容 | 建议 |
|---|---|
| 代码（模拟、动作迁移、界面、工具） | 你写的，可以用 MIT 或 Apache-2.0 |
| 奶蛙模型和贴图（`public/models/naiwa.glb`、`assets-src/naiwa/`） | 公开前去掉、换成原创角色，或者取得授权 |
| 参考图（`assets-src/naiwa/references/`） | 别人的图，不放进公开仓库 |
| 舞蹈数据（`public/dances/*.json`） | 是从别人的视频里提取的姿态数据，保留来源署名；不放心的话只用自己录的 |

在你决定之前，仓库保持私有，也不部署。
